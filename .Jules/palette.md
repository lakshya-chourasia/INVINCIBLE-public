## 2026-03-17 - Keyboard Accessibility in Interactive Menus
**Learning:** In complex visual components like `StaggeredMenuHeader`, using standard `div` elements for logos or toggle buttons completely hides them from keyboard and screen reader users. Simply adding `tabIndex={0}` is insufficient; they require explicit `role="button"`, `onKeyDown` handlers for Enter/Space, and dynamic `aria-label` attributes to explain state (e.g., 'Open menu' vs 'Close menu'). Furthermore, complex internal decorative elements should be hidden with `aria-hidden="true"` to prevent screen reader noise.
**Action:** Always pair `tabIndex={0}` with `role="button"` and an `onKeyDown` handler for custom interactive elements. Ensure stateful toggles have dynamic `aria-label`s and visible `:focus-visible` styles that don't rely solely on mouse hover states.
