## 2024-03-24 - Layout Thrashing in React RAF Loops
**Learning:** Calling `document.elementFromPoint` inside a `requestAnimationFrame` callback within high-frequency event handlers like `mousemove` forces synchronous layout recalculations (layout thrashing) because the browser must render the current frame to determine the element. Additionally, if caching `e.target` for the RAF loop, it must be defined in the outer scope of the handler (e.g. `let currentTarget`), not locally, to avoid stale closures where the RAF uses outdated targets.
**Action:** Always prefer capturing `e.target` from the original event rather than querying the DOM position synchronously during render cycles. Ensure any cached variables for RAF callbacks are scoped outside the event handler to capture the latest state.
