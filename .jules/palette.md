## 2024-05-18 - Form Field Accessibility in JoinCollective
**Learning:** The custom styled forms in this application (like the `JoinCollective` component) rely heavily on heavily customized UI components. When standard browser form inputs are restyled and nested within complex structures (like `SpotlightCard`), standard implicit label-wrapping is often abandoned in favor of structural grids. This decoupling necessitates strict adherence to explicitly associating `label` and `input` elements using `htmlFor` and `id` to maintain accessibility. Furthermore, as the forms rely on dynamic state to surface errors (e.g., `error_detected`), these custom error messages are entirely opaque to screen readers without ARIA alert roles.
**Action:** Always verify that complex form structures employ explicit label associations. Implement `role="alert"` and `aria-live="polite"` on any dynamically rendered error message elements, especially those styled as custom blocks rather than standard form validation popups.
