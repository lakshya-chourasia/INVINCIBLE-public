## 2024-04-13 - Improved Form Accessibility and ChatBot Screen Reader Support
**Learning:** In highly customized React forms (like `JoinCollective`), relying purely on nested labels or implicit structure can break screen reader focus if styles heavily modify default behavior. Adding explicit `htmlFor` on labels and matching `id` on inputs, along with `role="alert"` and `aria-live="polite"` on dynamic error message divs, drastically improves screen reader compatibility without altering the visual design. Similarly, custom icon-only buttons (like in `ChatBot`) must have explicit `aria-label` attributes.
**Action:** Always verify that every custom `<input>` has a distinct `id` mapping back to a `<label htmlFor="id">`. Ensure any dynamically appearing text block indicating an error uses `role="alert"` or `aria-live` regions so screen readers announce it instantly upon state change. Ensure icon-only buttons are given `aria-label` attributes.
